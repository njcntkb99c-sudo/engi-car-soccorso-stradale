# EN. GI CAR – Sito completo

Questa cartella contiene il sito professionale di EN. GI CAR – Soccorso Stradale H24.

## Struttura

- `index.html` — contenuto del sito
- `style.css` — grafica e responsive
- `script.js` — menu mobile, animazioni e invio posizione
- `assets/logo-engicar.png` — logo aziendale

## Come pubblicarlo su GitHub Pages

1. Apri il repository `engi-car-soccorso-stradale`.
2. Carica nella cartella principale:
   - `index.html`
   - `style.css`
   - `script.js`
   - `README.md`
3. Crea la cartella `assets`.
4. Dentro `assets`, carica `logo-engicar.png`.
5. Conferma con `Commit changes`.
6. Attendi 2–5 minuti e aggiorna il sito.

## Funzione “Invia posizione”

Il pulsante usa la geolocalizzazione del telefono. Dopo il consenso dell’utente, apre WhatsApp con un link Google Maps contenente le coordinate.
